# Lab 4 – String Functions

Two Java console programs practicing the Java standard class library and `String` methods.

## 1. Common Characters
Reads two sentences and builds a new string from the characters of the first sentence that also appear in the second, printed in uppercase. Spaces from the first sentence are kept; spaces from the second are ignored.

**Example:** "I like programming." + "I do not like programming." → `I LIKE PROGRAMMING.`

**Concepts:** `charAt`, `indexOf`, `toUpperCase`, string building with loops

## 2. Letter Counter
Reads a sentence and a letter, then counts how many times the letter appears, split into lowercase and uppercase occurrences.

**Example:** "This is an example of counting the letter T", `T` → 6 times (4 lowercase, 2 uppercase)

**Concepts:** `charAt`, `Character.toLowerCase` / `toUpperCase`, counting with loops
