# Lab 4 – String Functions

Two Java console programs practicing the Java standard class library and `String` methods.

## 1. Common Characters
Reads two sentences and builds a new string from the characters of the first sentence that also appear in the second. Spaces from the first sentence are kept; spaces from the second are ignored. Comparison is case-insensitive.

**Example:** "I like programming." + "I do not like programming." → `i like programming.`

**Concepts:** `charAt`, `toLowerCase`, nested loops, string building

## 2. Letter Counter
Reads a sentence and a letter, then counts how many times that letter appears in the sentence (case-insensitive).

**Example:** "This is an example of counting the letter T", `T` → appeared 6 times

**Concepts:** `charAt`, `toLowerCase`, counting with loops
