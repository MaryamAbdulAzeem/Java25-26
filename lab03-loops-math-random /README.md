# Lab 3 – Loops, Math Functions & Random Numbers

Three Java console programs practicing loops, the Java standard class library, `Math` functions and random number generation.

## 1. Access Code Verifier
Simulates a secure office door. The user gets three attempts to enter the correct access code; after three wrong attempts the system locks.
**Concepts:** loops, attempt counter, conditional exit

## 2. Pentagon Area Calculator
Asks for the number of regular pentagons and the side length of each, then calculates their total area rounded to two decimal places.
**Concepts:** `for` loops, `Math.sqrt`, `Math.pow`, rounding

## 3. Radar Scan Detection Simulation
Places random objects in a square zone around a radar at the origin and counts how many fall inside its circular detection range. Runs 100,000 and 1,000,000 scans and compares detection rates (a Monte Carlo simulation, approaching π/4 ≈ 78.5%).
**Concepts:** `Math.random` / `Random`, large loops, ratios and averages
