# Lab 2 – Smart Parking System

A Java console program that calculates parking fees for cars, bikes and trucks based on the number of hours parked.

## Features
- Menu to calculate a parking fee or exit the program
- Fee rates by vehicle type:
  - Car: 5 AED first hour, 3 AED each additional hour
  - Bike: 3 AED first hour, 2 AED each additional hour
  - Truck: 10 AED first hour, 7 AED each additional hour
- Case-insensitive vehicle input (e.g. "CaR" works)
- Validates input: rejects unknown vehicle types and durations of 0 or less

## Concepts used
`Scanner` input, `switch` and `if-else` statements, loops, and test-case documentation.
